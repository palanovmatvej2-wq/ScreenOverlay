ScreenOverlay-утилита, написанная на AutoHotkey (AHK) и скомпилированная в .exe, для мгновенного создания скриншотов-стикеров. Приложение позволяет в один клик зафиксировать любую часть экрана. Вместо обычного сохранения в файл, утилита мгновенно копирует снимок в буфер обмена и спавнит его по центру экрана в виде плавающего окна поверх всех приложений. Вы можете создавать сколько угодно таких окон одновременно, свободно перемещать их и настраивать под себя.

• Ctrl + Alt + S — сделать снимок экрана. Окно со скриншотом мгновенно появляется по центру поверх всех программ, а изображение копируется в буфер обмена.

• Ctrl + Alt + Q — закрыть все открытые окна со скриншотами.

• Alt + V — скрыть или показать обратно все созданные снимки.

• Alt + C — включить или выключить режим «кликанья сквозь картинки» (click-through), чтобы мышка игнорировала окна скриншотов и можно было работать с приложениями под ними.

• Клик колёсиком мыши (по конкретному окну) — мгновенно закрыть именно это выбранное окно со скриншотом.

• Прокрутка колёсика мыши (при наведении на снимок) — быстрое масштабирование и изменение размера выбранного скриншота.

• Зажатая левая кнопка мыши — свободное перетаскивание любого окна со снимком по экрану.

• Правая кнопка мыши (клик по снимку) — открыть контекстное меню для настройки индивидуальной прозрачности конкретного окна и других параметров.

🚀 Запуск и установка

Вы можете использовать проект двумя способами:
1. Готовый EXE-файл: Скачайте скомпилированный .exe из раздела Releases на GitHub и просто запустите его. Установка не требуется.
2. Исходный код AHK: Если у вас установлен AutoHotkey, вы можете запустить напрямую исходный файл скрипта или скомпилировать его самостоятельно.
